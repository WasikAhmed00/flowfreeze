# Synthetic demo data

The CSV files and `flowfreeze.db` in this folder are generated by `data_generator/generate.py`. They contain synthetic records only and do not represent upay production data or customer behavior.

By default, the generator creates 100 varied instances of each of the eight scenario families (800 incident cases total), plus benign historical transactions. From the repository root, regenerate the same dataset with:

```powershell
python -m data_generator.generate --seed 42 --cases-per-scenario 100
```

Use another integer seed to create a different deterministic set of case amounts, event timing, profile attributes, and split assignments. `--cases-per-scenario` can adjust the population. The generator replaces the derived local SQLite file and rewrites the CSV outputs. `generation_metadata.json` records counts, split sizes, seed, and synthetic-data warning.

Train/validation/test splits are stratified by scenario family but assigned to complete scenario instances. All wallet and transaction rows from a case stay together. The `split` value is carried in `ground_truth.csv` for evaluation and must not be used as a model feature. Synthetic training results are not evidence of upay production performance.
