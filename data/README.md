# Synthetic demo data

The CSV files and `flowfreeze.db` in this folder are generated by `data_generator/generate.py`. They contain synthetic records only and do not represent upay production data or customer behavior.

From the repository root, regenerate the same dataset with:

```powershell
python -m data_generator.generate --seed 42
```

Use another integer seed to create a different deterministic set of profile attributes. The generator replaces the derived local SQLite file and rewrites the CSV outputs. `generation_metadata.json` records the seed and synthetic-data warning.

The train/validation/test value is assigned at scenario-family level in `data_generator/config.py`; it is carried in `ground_truth.csv` for evaluation and must not be used as a model feature.
